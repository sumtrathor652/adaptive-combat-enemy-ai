ADAPTIVE COMBAT ENEMY AI - INTERFACE AND CONTROL UPDATE

The game title now matches the project folder name: Adaptive Combat Enemy AI.

Controls:
W/S = Move forward/backward
A/D = Move left/right
J = Light attack
K = Heavy attack / guard break
L = Hold to block
SPACE = Dodge
E = Blind ability
R = Next round (AI learning continues)
F9 = Reset saved AI learning profile
ESC = Return to the main menu

The existing Markov prediction, Q-learning, adaptive difficulty, combat actions,
telemetry HUD, and player profile are retained.
