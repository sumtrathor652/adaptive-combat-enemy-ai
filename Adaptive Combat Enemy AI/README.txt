# Adaptive Combat Enemy AI

## Run
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install the dependency: `python -m pip install pygame`
4. Start the game: `python main.py`

## Controls
- W / S: Move forward / backward
- A / D: Move left / right
- J: Light attack
- K: Heavy attack / guard break
- Hold L: Block
- SPACE: Dodge in the current movement direction
- E: Special blind ability
- R: Start next round (AI learning continues)
- F9: Reset saved AI learning profile
- ESC: Return to main menu

The Markov prediction, Q-learning, adaptive difficulty, combat actions, telemetry HUD,
and saved player profile are preserved.
